# 🚀 SPACE DODGER
### A little arcade game. A big test of your reflexes.

Welcome to **Space Dodger** — a browser game where your only job is to keep your spaceship in one piece. Asteroids are coming down, the speed keeps getting tougher, and one small mistake can end your mission.

No frameworks. No complicated setup. Just HTML, CSS and JavaScript.

---

## 🌌 Game preview

- Move your rocket left and right.
- Dodge the falling asteroids.
- Earn 5 points every time an asteroid passes safely.
- You have 3 lives.
- Beat your personal high score and try again.

## 🎮 Controls

| Action | Controls |
| --- | --- |
| Move left | `←` or `A` |
| Move right | `→` or `D` |
| Pause / resume | `Space` or Pause button |
| Mobile movement | Hold the on-screen arrows |

## ✨ Features

- Clean space-inspired interface
- Keyboard and mobile touch controls
- Score and three-life system
- Asteroids get faster as your score increases
- Pause, resume and restart options
- Best score saved in your browser with `localStorage`
- Responsive layout for phone and desktop
- Simple code that is easy to read and edit

## 🛠️ Run it on your computer

1. Download or clone this project.
2. Open the `space-dodger` folder in VS Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code and click **Go Live**.

No installation and no extra packages needed.
